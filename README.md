# Parcial_1_FullStackII

## React

La aplicación React está dentro de frontend.

Para instalar y ejecutar:
cd frontend _aquí está la aplicación React_
npm install _instala dependencias, se ejecuta solo 1 vez y si cambian las dependencias_
npm run dev _inicia servidor, muestra la app en navegador,  para salir ctrl+c_

npm run build _prepara la app para publicarla, debe correr sin errores_
